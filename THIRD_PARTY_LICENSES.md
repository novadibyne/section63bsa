# Third-party licences

Legal Sakshya is built with open-source software. This file lists every package whose code is, or may be, sent to people's browsers when they use the app, with its licence. Tools used only to build and test the app are listed separately at the end.

Generated by `npm run licenses` on 2026-10-29. The shipped list combines what the production build's source maps show and every dependency of the app with everything it depends on, so nothing that reaches visitors is missed. It may include a few helper packages that a library only uses outside the browser.

## Summary

- **134 packages are shipped in the app.** Licences: MIT (107), Apache-2.0 (10), ISC (5), OFL-1.1 (4), Unlicense (2), 0BSD (2), BSD-3-Clause (1), (MIT AND Zlib) (1), (MIT OR CC0-1.0) (1), BSD-2-Clause (1).
- **All of them are permissive licences** that allow free commercial use. They only ask that the copyright and licence notices are kept, which this file and the licence comments kept in the bundled code do.
- **No GPL, LGPL or AGPL code is shipped.** jszip is offered under "MIT or GPL-3.0"; the app uses it under MIT.
- **Fonts** (Inter, Plus Jakarta Sans, JetBrains Mono, Source Serif 4) are under the SIL Open Font License 1.1, which allows bundling them in an app, including a commercial one. They may not be sold on their own.
- **Apache-2.0** packages (for example Tesseract, dexie, zxing-cpp): keep their licence and any NOTICE file when redistributing. The licence files are copied next to the scan engines in `public/vendor/`.
- **Build-only tools are not shipped.** Two of them have non-permissive licences: `sharp` / `libvips` (LGPL-3.0), which Next.js uses to resize images on a server (this static site turns that off and never includes it), and `caniuse-lite` (CC-BY-4.0), browser-support data used at build time.
